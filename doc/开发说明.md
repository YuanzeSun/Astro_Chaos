# 开发说明

## 跑起来

```bash
npm install
npm run dev       # 服务端和 Vite 一起起，打开 http://127.0.0.1:5178/
npm start         # 打包后由服务端直接提供页面，打开 http://127.0.0.1:8765/
npm test          # 引擎、题库、事件内容、服务端的检查
npm run sim       # 跑几百局模拟，看结局分布，调数值用
npm run typecheck
```

`npm run build` 会生成单个文件 `dist/index.html`，直接双击就能玩，只是没有 AI 群友。

## 代码地图

```text
src/
  engine/   游戏规则：日历、天气月相、学生、事件、比赛、结局
  data/     内容：特性、活动、事件、比赛、题库、器材、结局、成就、星表
  ui/       界面（React）
  ai/       AI 群友的前端
server/     本机服务端：读 CLI 凭据、ChatGPT 登录、DeepSeek、调模型
scripts/    数值模拟、星表生成、开发启动
tests/      单元测试和模拟器
```

- 数值旋钮集中在 `src/engine/balance.ts`。
- 加事件：往 `src/data/events.ts` 里加一条，文本里的 `{a}`、`{b}` 会替换成学生的名字。
- 星表来自 [d3-celestial](https://github.com/ofrohn/d3-celestial)（BSD-3-Clause, Olaf Frohn）。重新生成：`node scripts/build-sky.mjs <d3-celestial 的 data 目录>`。

## AI 群友

每个月结束时，前端把这个月的群聊摘要发给本机服务端（`POST /api/ai/banter`），服务端调模型，返回几条台词。模型按顺序从这些地方找：

1. 设置里手动选的模型。
2. Claude Code：`~/.claude/settings.json` 的 `env`（`ANTHROPIC_API_KEY` 或 `ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_BASE_URL`、`ANTHROPIC_MODEL` 等）。没写模型就用 `claude-opus-5-5`。
3. Codex：`~/.codex/config.toml` 和 `auth.json`。
4. 设置里的 ChatGPT 登录（OAuth + PKCE，回调 `http://127.0.0.1:8765/auth/callback`）。
5. 设置里填的 DeepSeek key。

默认那一家第一次用之前会先发一个很小的请求试一下；有的中转站只接受它自家 CLI 的请求，不通就换下一家。

- 密钥只留在服务端进程里，不进浏览器，不写日志。
- 在游戏里接上的账号和选的模型存在 `~/.config/astro-chaos/`，权限 600。
- 服务端只监听 127.0.0.1，主机名不是本机的请求、从别的网站发来的请求一律拒绝。

可用的环境变量：`PORT`、`CLAUDE_CONFIG_DIR`、`CODEX_HOME`、`ASTRO_CHAOS_CONFIG_DIR`、`LLM_REFUSAL_FALLBACK`（`auto` / `on` / `off`）。
